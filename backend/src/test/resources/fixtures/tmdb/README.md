# TMDB test fixtures

Hand-written JSON in TMDB's response format, with made-up titles ("Example Movie").
Not real TMDB data: TMDB's terms forbid storing their content for more than 6 months or
redistributing it, so real responses (docs/samples/tmdb_*.json) stay local and gitignored.
Extra fields we don't use are included on purpose, to check they are ignored.
